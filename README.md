# mini Thread 3D 

[Русский](#русский) | [English](#english)

## 📌 Русский

**mini Thread 3D** – это интерактивное веб-приложение для параметрического моделирования трапецеидальной резьбы (внешней и внутренней) с возможностью визуализации в реальном времени и экспорта в STL.

### 🧰 Возможности
- Построение 3D-модели внешней или внутренней трапецеидальной резьбы
- Регулировка параметров: наружный/внутренний диаметр, шаг, высота, плоская часть
- Сквозное отверстие (внешняя резьба) или гладкий внешний цилиндр (внутренняя резьба)
- Прозрачный и каркасный режимы отображения
- Экспорт готовой модели в файл STL (бинарный)
- Управление камерой (орбита) – мышь / touch

### 🖥️ Использование
1. Откройте файл `mini-thread-3d.html` в любом современном браузере (Chrome, Firefox, Edge).
2. Настройте параметры резьбы в левой панели.
3. Вращайте/масштабируйте сцену для осмотра модели.
4. Нажмите **ЭКСПОРТ STL** для сохранения модели.

### 🛠️ Технологии
- [Three.js](https://threejs.org/) (MIT License)
- Чистый HTML/CSS/JS

### 📁 Структура
- Один HTML-файл, содержащий всю логику и стили.

## 🇬🇧 English

**Trapezoidal Thread 3D Generator** is an interactive web app for parametric modeling of trapezoidal threads (external and internal) with real-time visualization and STL export.

### 🧰 Features
- Build 3D models of external or internal trapezoidal threads
- Adjustable parameters: major/minor radius, pitch, height, flat portion
- Through hole (external thread) or smooth outer cylinder (internal thread)
- Transparent and wireframe display modes
- Export model to STL file (binary)
- Orbit camera control (mouse / touch)

### 🖥️ Usage
1. Open `index.html` in any modern browser (Chrome, Firefox, Edge).
2. Adjust thread parameters in the left panel.
3. Rotate/zoom the scene to inspect the model.
4. Click **EXPORT STL** to save the model.

### 🛠️ Technologies
- [Three.js](https://threejs.org/) (MIT License)
- Pure HTML/CSS/JS
